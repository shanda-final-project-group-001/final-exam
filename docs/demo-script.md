## 1. 演示前 10 分钟准备

```powershell

python -m scripts.check_data
python -m scripts.check_agent

# 3. 启动界面

```

检查项：

- 浏览器打开 `http://localhost:8501`，缩放 100%，窗口最大化
- 左侧“运行模式”显示“在线（模型服务）”；若出现黄条警告，说明 Key 未配置，改用离线模式
- 关闭系统通知与聊天软件，避免弹窗入镜
- 提前打开 `workspace/` 文件夹，演示结束时展示产出
- **不要打开 `.env`**，讲密钥时只说“放在 `.env`，已被 Git 忽略”

## 4. 故障兜底

| 故障 | 处理 |
|---|---|
| 模型超时或报错 | 左侧切“离线演示（预置流程）”，重跑同一句；说明“工具与数据完全一致，只是不调用模型” |
| 界面打不开 | 终端执行 `python -m volunteer.agent --offline`，展示同一批工具与产出 |
| 网络完全不可用 | 播放 3 分钟录屏，并说明现场环境限制 |
| 数据被改乱 | `python -m data.seed` 重建，约 1 秒 |
| 误点删除会话 | 新建对话即可，不影响数据 |

## 6. 逐页讲稿计时（8 分钟版）

按 `presentation.html` 每页的演讲者备注字数估算，语速取 240 字/分钟（4 字/秒，正常汇报语速，不含停顿）。

| 页 | 主题 | 备注字数 | 预计用时 | 累积 |
|---|---|---|---|---|
| 1 | 封面与自我介绍 | 119 | 0:30 | 0:30 |
| 2 | 目录：今天讲六件事 | 45 | 0:11 | 0:41 |
| 3 | 痛点：信息散落、统计靠人 | 72 | 0:18 | 0:59 |
| 4 | 主路径：一句话串五个动作 | 73 | 0:18 | 1:17 |
| 5 | 五层架构 | 192 | 0:48 | 2:05 |
| 6 | 工具 / MCP / Skill 各管什么 | 115 | 0:29 | 2:34 |
| 7 | 与课堂实验的关系、增量 | 84 | 0:21 | 2:55 |
| 8 | 合规与数据边界 | 63 | 0:16 | 3:11 |
| 9 | **现场演示（四条话术）** | 108（引导语） | 0:27 + 现场 3:30 | 3:38 → 7:08 |
| 10 | 不足与后续 | 55 | 0:14 | 7:22 |
| 11 | 致谢 | 54 | 0:13 | 7:35 |

结论：讲稿总量约 980 字，约 **4 分钟口头内容 + 3.5 分钟演示 = 7 分 35 秒**，留 25 秒缓冲，卡在 8 分钟内。
若现场超时，先砍第 8 页（合规）压缩到 8 秒，再砍第 2 页目录（可直接翻页带过），不要砍第 5 页架构和第 6 页分工——这两页是老师最常追问的地方。

计时演练做法（T8.2）：手机秒表从第 1 页开始，两人各念一遍，记录每页实际用时，超过上表 50% 的页面就删句；
演练两遍都落在 7:20–7:50 之间即可冻结讲稿。录屏旁白的逐字稿见 [recording-guide.md](recording-guide.md)。
