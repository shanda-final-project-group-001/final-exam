> 目标：180 秒以内，720p 以上，全程不出现 `.env` 与任何 Key。

## 1. 录制前 10 分钟（照着敲，别临场想）

```powershell
# 1) 回到数据基线：S001 累计 18.5 小时、A005 满员、A001 有名额
.\.venv\Scripts\Activate.ps1
python -m data.seed

# 2) 三项自检必须全 PASS，任一失败就先修，别录
python -m scripts.check_data
python -m scripts.check_agent
python -m scripts.smoke_ui

# 3) 起界面
streamlit run web.py
```

窗口与桌面设置：

- [ ] 浏览器 `http://localhost:8501`，缩放 100%，窗口最大化，只留这一个标签页
- [ ] 左侧"运行模式"确认是 **在线（模型服务）**；若是离线，说明 Key 没配，录屏改走离线模式并在旁白里说明
- [ ] 关闭微信、QQ、邮件与系统通知（Windows：设置 → 系统 → 通知 → 关闭）
- [ ] 资源管理器提前打开 `workspace/` 与 `workspace/reports/`，最后一步不现找
- [ ] 终端窗口滚到看不见历史命令的位置，**绝不切到含 Key 的窗口**
- [ ] 鼠标移动放慢，点击后停 1 秒再动，方便观看

录制工具：Win + G（系统自带录屏，只录当前窗口）或 OBS（1080p / 30fps / 麦克风单独轨）。
录制文件命名：`志愿星-备份录屏-2026102X.mp4`，放仓库外的 `录屏/` 目录，另存一份网盘。

## 2. 逐字旁白（总 177 秒，约 640 字）

> 括号里是剩余时间，念快了就删破折号后的补充句，别删主干。

### 0:00–0:15 首屏（50 字）

> 「这是志愿星，一个校园志愿活动的智能体。它不只是聊天，而是把找活动、查冲突、报名、统计时长串成一句话。」（0:00）

画面：停在首屏，不要动。

### 0:15–0:50 找活动（120 字）

> 「先说需求：我周三晚上有空，帮我找两个合适的活动。看右边的执行面板——它先读了匹配规则，再调 `search_activities` 查库。」（0:18）
>
> 「结果里的剩余名额是数据库实时算出来的，不是模型编的。三个候选按校内优先、周末优先排序，正好是我在 `AGENTS.md` 里写过的偏好。」（0:34）

操作：点示例话术「周三晚上找活动」，结果出来后鼠标划一下执行面板。

### 0:50–1:20 冲突拦截（110 字）

> 「第二条，我要报名秋季运动会志愿保障。它没有直接报，而是先查课表冲突，发现和周三的数据结构课重叠，于是把冲突课程和时段摆出来，让我自己决定。」（1:10）

操作：输入话术 → 等冲突结论出现 → 停在冲突提示上 2 秒。

### 1:20–1:55 人工确认（120 字）

> 「换一个不冲突的：社区长者手机课堂。报名属于写操作，所以这里弹出确认，确认之前数据库一个字都没改。」（1:35）
>
> 「点确认执行——名额从十变成九，执行面板里能看到 `enroll_activity` 的返回。」（1:45）

操作：输入话术 → 点「确认执行」→ 鼠标指向名额变化处。

### 1:55–2:35 周报（140 字）

> 「最后是学期末最烦的事：统计时长。一句话，它先查时长汇总，再按 Skill 里的模板写周报，导出 CSV，最后还起了子代理复核数字。」（2:15）
>
> 「执行面板里这五步是真实调用：查时长、导 CSV、读模板、写文件、critic 复核。」（2:30）

操作：输入「把这学期时长汇总成周报，导出 CSV」→ 完成后停住。

### 2:35–3:00 产出（85 字）

> 「产出都在 `workspace` 里：周报是 Markdown，CSV 用 UTF-8-SIG 编码，Excel 打开中文不乱码。十八点五小时，六条记录，和数据库完全对得上。」（2:55）
>
> 「以上是备份演示，完整说明在仓库的 README 里。」（3:00）

操作：资源管理器里依次点开 `reports/*.md` 与 `hours.csv`，最后停在 CSV 内容上。
